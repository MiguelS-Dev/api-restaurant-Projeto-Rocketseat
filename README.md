# API Restaurant

API REST desenvolvida durante os estudos com Node.js e o conteúdo da Rocketseat, com o objetivo de praticar conceitos de desenvolvimento back-end, criação de rotas, manipulação de dados e integração com banco de dados.

## Sobre o projeto

Este projeto foi desenvolvido como parte dos meus estudos de desenvolvimento back-end.

A aplicação simula uma API para gerenciamento de um restaurante, permitindo trabalhar na criação de recursos, organização das rotas e comunicação entre a aplicação e o banco de dados.

O projeto também foi importante para colocar em prática conceitos de APIs REST e desenvolvimento de aplicações utilizando JavaScript/TypeScript no back-end.

## Tecnologias

## Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/MiguelS-Dev/api-restaurant-Projeto-Rocketseat.git
```

### 2. Entre na pasta

```bash
cd api-restaurant-Projeto-Rocketseat
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute as migrations

```bash
npm run knex -- migrate:latest
```

### 5. Inicie o projeto

```bash
npm run dev
```

A API ficará disponível localmente na porta configurada no projeto.
